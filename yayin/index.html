02Erişilebilirlik#

  • Yalnızca ikon içeren her butona aria-label ver.
  • Görsellere anlamlı alt yaz; süs görsellerinde alt="".
  • Her form alanının bir <label>’ı olsun.
  • Sayfanın başına “İçeriğe atla” bağlantısı koy.
  • Metin kontrastı en az 4,5:1 olsun (fkdev renkleri bunu sağlar).
  • Her şey klavyeyle kullanılabilsin; odak halkasını kaldırma.
  • Hareket prefers-reduced-motion açıksa kapansın (fkdev UI bunu otomatik yapar).

03Performans#

  • Fontlar için preconnect kullan, display=swap ile yükle.
  • Betikleri defer ile yükle.
  • Görselleri WebP/AVIF olarak ve loading="lazy", width, height ile ekle.
  • Cam efekti (backdrop-filter) pahalıdır; aynı ekranda düzinelerce büyük cam yüzey kullanma.
  • HTML’i kısa, CSS ve JS’i uzun süre önbellekte tut.

04Güvenlik başlıkları#

.htaccess.htaccess
Options -Indexes
ErrorDocument 404 /404.html

<IfModule mod_rewrite.c>
  RewriteEngine On
  RewriteCond %{HTTPS} !=on
  RewriteRule ^ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]
</IfModule>

<IfModule mod_headers.c>
  Header always set X-Content-Type-Options "nosniff"
  Header always set X-Frame-Options "SAMEORIGIN"
  Header always set Referrer-Policy "strict-origin-when-cross-origin"
  Header always set Permissions-Policy "camera=(), microphone=(), geolocation=()"
  Header always set Content-Security-Policy "default-src 'self'; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com https://ui.fkdev.sbs; font-src https://fonts.gstatic.com; script-src 'self' 'unsafe-inline' https://ui.fkdev.sbs; img-src 'self' data:"
</IfModule>

CSP’yi dikkatli açContent-Security-Policy yanlış ayarlanırsa fontlar ve betikler engellenir. Önce tarayıcı konsolunu izleyerek Content-Security-Policy-Report-Only ile dene.

05Deploy#

OrtamNasıl?
Paylaşımlı hosting (Apache)Dosyaları public_html içine yükle; .htaccess dosyasının da yüklendiğinden emin ol (gizli dosya olarak atlanabilir).
Vercelvercel komutu ya da GitHub bağlantısı; statik sitede ayar gerekmez.
Netlify / Cloudflare PagesKlasörü sürükle-bırak; 404 için 404.html otomatik kullanılır.
Kendi sunucun (Nginx)try_files $uri $uri/ /404.html; ve HTTPS için Let’s Encrypt.
