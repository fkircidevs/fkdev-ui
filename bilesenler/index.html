06Breadcrumb#

Sayfanın sitedeki yerini gösterir. <ol> ile kurulur; son öğe aria-current="page" taşır.

SEO ipucuBreadcrumb’ı JSON-LD BreadcrumbList ile de işaretle; Google arama sonuçlarında sayfa yolunu gösterir. Örnek için SEO bölümüne bak.

11Confirm (onay penceresi)#

Tek satır JS ile Promise döndüren onay penceresi. Ekstra HTML yazmana gerek yok; tarayıcının çirkin confirm() kutusunun yerini alır.

JavaScript
document.getElementById('demo-confirm').addEventListener('click', async () => {
  const ok = await FK.confirm({
    title: 'Dosya silinsin mi?',
    text: 'proje.zip kalıcı olarak silinecek. Bu işlem geri alınamaz.',
    ok: 'Evet, sil',
    cancel: 'Vazgeç',
    danger: true
  });
  FK.toast(ok ? 'Dosya silindi' : 'İşlem iptal edildi', ok ? 'success' : 'info');
});
SeçenekVarsayılanAçıklama
title“Emin misin?”Başlık
text—Açıklama metni
ok / cancel“Onayla” / “Vazgeç”Buton yazıları
dangerfalseOnay butonunu kırmızı yapar

Sıralanabilir tablo

Tabloya data-fk-sort ekle; başlıklara tıklayınca sıralanır. Sayılar ve tarihler için başlığa data-fk-type="number" / "date" ver; hücrede ham değer gerekiyorsa data-value kullan.

JavaScriptSıralama olayı
document.querySelector('table').addEventListener('fk:sort', (e) => console.log(e.detail.column, e.detail.direction));

36Toast (bildirim)#

Sağ altta beliren, kendiliğinden kapanan bildirim. HTML özniteliği ya da JS ile tetiklenir.

JavaScript
FK.toast('Dosya yüklendi', 'success');
FK.toast('Bağlantı koptu', 'danger', 8000);

37Tooltip (ipucu)#

v2.4.1 ile tooltip artık sayfanın en üst katmanında çizilir: taşan kapsayıcılar (tablolar, butonlar) onu kesmez, ekran kenarına çarpmaz, kaydırınca ve Esc ile kapanır.

ErişilebilirlikTooltip yalnızca ek bilgi içindir. Butonun asıl adını mutlaka aria-label ile ver. Açıkken öğeye aria-describedby otomatik bağlanır.
