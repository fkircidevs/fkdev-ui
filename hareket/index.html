Hareket · JavaScript API

Hareket, yumuşakça.

Animasyonlar dikkat çekmek için değil, akışı anlatmak için vardır. Hepsi “azaltılmış hareket” ayarına saygı duyar.

01Hareket ilkeleri#

DeğişkenEğriNe zaman?
--fk-easecubic-bezier(.16, 1, .3, 1)Çoğu geçiş: hızlı başlar, yumuşak durur
--fk-ease-iocubic-bezier(.76, 0, .24, 1)Perde, menü gibi büyük yüzeyler
--fk-springcubic-bezier(.34, 1.56, .64, 1)Hafif yaylanma: rozet, onay işareti, gösterge
  • Küçük öğeler 300–500 ms, büyük yüzeyler 800–1200 ms.
  • Aynı anda tek bir şey hareket etsin; gerekiyorsa 60 ms arayla sırala.
  • Kullanıcı prefers-reduced-motion açtıysa hareket kapanır, içerik hemen görünür.

02Belirme (reveal)#

fk-reveal alan öğe ekrana girince bulanıktan netleşerek yukarı kayar. --d ile gecikme verilir.

03Kelime kelime başlık#

data-fk-split başlığı kelimelere böler; ekrana girince kelimeler sırayla aşağıdan yükselir. Ekran okuyucular metni normal okur.

06JavaScript API#

fkdev-ui.js yüklendiğinde sayfadaki tüm bileşenleri otomatik başlatır ve global bir FK nesnesi oluşturur.

MetotDönerAçıklama
FK.toast(mesaj, tür?, ms?)kapatma fonksiyonuBildirim gösterir. tür: info | success | warning | danger
FK.confirm(ayarlar)Promise<boolean>Onay penceresi açar; Onayla → true
FK.open("#id") / FK.close("#id")dialogModal ya da drawer açar/kapatır
FK.setTheme("dark" | "light")—Temayı değiştirir ve hatırlar
FK.theme()"dark" | "light"Geçerli tema
FK.copy(metin)PromisePanoya kopyalar
FK.sort(tablo, th)—Tabloyu bir sütuna göre sıralar
FK.init(kök?)—Sonradan eklenen HTML’i başlatır (AJAX, React, Vue sonrası); aynı öğeyi iki kez bağlamaz
FK.split(öğe)—Bir başlığı elle kelimelere böler
FK.version"2.4.1"Kütüphane sürümü

Olaylar

Bileşenler fk: önekli olaylar yayar; hepsi yukarı doğru kabarır (bubbles), bu yüzden document üzerinde de dinleyebilirsin.

OlayKaynakevent.detail
fk:ready<html>{ version }
fk:theme<html>{ theme }
fk:open / fk:closedialog{ value } (kapanışta düğmenin data-fk-close değeri)
fk:tab[data-fk-tabs]{ tab }
fk:sorttablo{ column, direction }
fk:complete.fk-otp{ value }
fk:tags.fk-tags{ values }
JavaScriptTema değişimini dinle
document.addEventListener('fk:theme', (e) => {
  console.log('Yeni tema:', e.detail.theme);
});
JavaScriptDinamik içerik
const kart = document.createElement('div');
kart.innerHTML = '<button class="fk-btn fk-btn-primary" data-fk-toast="Merhaba!">Dene</button>';
document.body.appendChild(kart);
FK.init(kart);
