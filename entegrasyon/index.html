01Saf HTML#

Hiçbir araç gerekmez. İlk sayfa şablonunu al, her sayfayı kendi klasörüne index.html olarak koy, sunucuya yükle.

function csrf_field(): string { return '<input type="hidden" name="csrf" value="' . e($_SESSION['csrf']) . '">'; }
function flash(string $msg, string $type = 'success'): void { $_SESSION['flash'] = [$msg, $type]; }

03PHP: form işleme#

PHPapi/iletisim.php
<?php
require __DIR__ . '/../inc/config.php';
require __DIR__ . '/../config/db.php';

if ($_SERVER['REQUEST_METHOD'] !== 'POST' || !hash_equals($_SESSION['csrf'] ?? '', $_POST['csrf'] ?? '')) {
  http_response_code(403);
  exit('Geçersiz istek.');
}

$ad    = trim($_POST['ad'] ?? '');
$mail  = trim($_POST['mail'] ?? '');
$mesaj = trim($_POST['mesaj'] ?? '');

if (mb_strlen($ad) < 2 || !filter_var($mail, FILTER_VALIDATE_EMAIL) || mb_strlen($mesaj) < 10) {
  flash('Lütfen alanları kontrol edin.', 'danger');
  header('Location: /iletisim/');
  exit;
}

$stmt = db()->prepare('INSERT INTO messages (channel, name, email, body, ip) VALUES (?, ?, ?, ?, ?)');
$stmt->execute(['contact', $ad, $mail, $mesaj, $_SERVER['REMOTE_ADDR'] ?? '']);

flash('Mesajın iletildi, teşekkürler!');
header('Location: /iletisim/');
PHPDosya yükleme (özet)
<?php
$f = $_FILES['dosya'] ?? null;
if (!$f || $f['error'] !== UPLOAD_ERR_OK || $f['size'] > 150 * 1024 * 1024) exit('Geçersiz dosya.');
$ext  = strtolower(pathinfo($f['name'], PATHINFO_EXTENSION));
$izin = ['pdf', 'zip', 'png', 'jpg', 'jpeg', 'docx', 'xlsx'];
if (!in_array($ext, $izin, true)) exit('Bu dosya türü kabul edilmiyor.');
$hedef = __DIR__ . '/../storage/' . bin2hex(random_bytes(16)) . '.' . $ext;
move_uploaded_file($f['tmp_name'], $hedef);

storage klasörünü dışarı kapatYüklenen dosyaların durduğu klasör web’den doğrudan erişilebilir olmamalı. Mümkünse public klasörün dışına koy ya da içine Require all denied içeren bir .htaccess yerleştir.

04Node.js / Express#

Terminal
npm init -y
npm install express
JavaScriptindex.js
const express = require('express');
const path = require('path');
const app = express();

app.use(express.static(path.join(__dirname, 'public'), { extensions: ['html'] }));
app.use(express.json());

app.post('/api/iletisim', (req, res) => {
  const { ad, mail, mesaj } = req.body || {};
  if (!ad || !mail || !mesaj) return res.status(400).json({ ok: false, error: 'Eksik alan' });
  res.json({ ok: true });
});

app.use((req, res) => res.status(404).sendFile(path.join(__dirname, 'public', '404.html')));

if (require.main === module) app.listen(process.env.PORT || 3000);
module.exports = app;

05Vercel#

Statik bir fkdev UI sitesi Vercel’e ek ayar olmadan yüklenir. Express uygulaması için:

JSONvercel.json
{
  "version": 2,
  "builds": [{ "src": "index.js", "use": "@vercel/node" }],
  "routes": [{ "src": "/(.*)", "dest": "/index.js" }]
}

Vercel sınırlarıVercel fonksiyonlarında istek gövdesi 4,5 MB ile sınırlıdır; büyük dosya yüklemeleri doğrudan bir depolamaya (ör. Vercel Blob) yapılmalı. Bellekte tutulan oturumlar da kopyalar arasında paylaşılmaz; oturumu veritabanında ya da imzalı çerezde tut.

06React ve Next.js#

CSS’i bir kez global olarak içe aktar, class yerine className kullan. Sayfa değiştikçe yeni öğeleri başlatmak için FK.init() çağır.

JavaScriptapp/layout.jsx
import Script from 'next/script';
import './fkdev-ui.css';

export default function RootLayout({ children }) {
  return (
    <html lang="tr">
      <body className="fk-body fk-atmosphere">
        {children}
        <Script src="/fkdev-ui.js" strategy="afterInteractive" />
      </body>
    </html>
  );
}
JavaScriptcomponents/Kart.jsx
import { useEffect, useRef } from 'react';

export function Kart({ baslik, children }) {
  const ref = useRef(null);
  useEffect(() => { window.FK && window.FK.init(ref.current); }, []);
  return (
    <article ref={ref} className="fk-card fk-reveal">
      <h3 className="fk-card-title">{baslik}</h3>
      <p>{children}</p>
    </article>
  );
}
