Formlar · Alanlar ve doğrulama

Formlar, sürtünmesiz.

Her alan aynı yapıyı izler: etiket, alan, ipucu ve hata. Doğrulama tarayıcının yerleşik kurallarını kullanır, mesajları Türkçeleştirir.

01Alan yapısı#

Her alan bir fk-field içinde durur. Etiket for ile alana bağlanır; hata mesajı fk-error içinde gösterilir.

Sınıf / öznitelikAçıklama
fk-formAlanları 20px aralıkla dizen ızgara
fk-form-rowYan yana 2 alan; telefonda alt alta
fk-fieldTek alanın kapsayıcısı; hata durumunda is-invalid alır
fk-label / fk-reqEtiket / zorunlu yıldızı
fk-hint / fk-errorYardım metni / hata metni

05Karakter sayacı#

Alanı kapsayan öğeye data-fk-counter ekle; sınır maxlength’ten okunur. Sınırın %90’ında sayaç sarıya, sınırda kırmızıya döner.

06Doğrulama kodu (OTP)#

Yazınca sonraki kutuya geçer, silince geri döner, yapıştırılan kodu kutulara dağıtır, telefonda SMS kodunu otomatik önerir. Tüm haneler dolunca fk:complete olayı tetiklenir ve kod gizli alana yazılır.

JavaScript
document.querySelector('.fk-otp').addEventListener('fk:complete', (e) => {
  fetch('/api/dogrula', { method: 'POST', body: new URLSearchParams({ kod: e.detail.value }) });
});

10Dosya yükleme#

Seçilen dosyanın adı ve boyutu fk-drop-file içine otomatik yazılır. Sunucu tarafı için PHP form işleme ve dosyalar tablosu için veritabanı şemasına bak.

11Doğrulama#

Forma data-fk-validate ekle. Alanlar odaktan çıkınca kontrol edilir; gönderirken hatalı ilk alana odaklanılır ve bildirim gösterilir. Kurallar yerleşik HTML öznitelikleridir: required, type="email", minlength, pattern…

Sınıf / öznitelikAçıklama
form[data-fk-validate]Doğrulamayı açar (tarayıcı balonlarını kapatır)
data-fk-msgAlan için özel hata mesajı
data-fk-errorForm genel hata bildirimi
data-fk-demoSadece demo: gerçekten göndermez, başarı bildirimi gösterir
data-fk-successDemo başarı mesajı

Sunucuda da doğrulaTarayıcı doğrulaması kullanıcı deneyimi içindir; güvenlik değildir. Her alanı sunucuda yeniden kontrol et.

13Formu sunucuya gönderme#

Formu sayfayı yenilemeden göndermek için fetch kullan; sonucu FK.toast ile göster.

JavaScript
document.querySelector('#iletisim').addEventListener('submit', async (e) => {
  e.preventDefault();
  const form = e.currentTarget;
  const btn = form.querySelector('[type="submit"]');
  btn.classList.add('is-loading');
  try {
    const res = await fetch('/api/iletisim.php', { method: 'POST', body: new FormData(form) });
    const data = await res.json();
    if (!res.ok || !data.ok) throw new Error(data.error || 'Gönderilemedi');
    form.reset();
    FK.toast('Mesajın iletildi!', 'success');
  } catch (err) {
    FK.toast(err.message, 'danger');
  } finally {
    btn.classList.remove('is-loading');
  }
});

PHP tarafı (doğrulama, CSRF, veritabanına yazma) için Framework & PHP sayfasına geç.
