Uygulama · Claude API

Sitene yapay zekâ.

Bu rehber Anthropic’in Claude modellerini kendi sitene güvenle bağlamayı anlatır: anahtar sunucuda kalır, tarayıcı yalnızca kendi API’ni çağırır.

01Mimari: anahtar asla tarayıcıda değil#

Tarayıcıfk-chat arayüzü
fetch /api/chat
Senin sunucunPHP · Node · .env anahtar
HTTPS + x-api-key
Claude APIapi.anthropic.com

Altın kuralAPI anahtarını HTML’e, JavaScript dosyasına ya da GitHub’a koyma. Tarayıcıya giden her şey herkese açıktır; anahtarını bulan biri senin hesabından harcama yapar.

  1. Anthropic Console’dan bir API anahtarı oluştur.
  2. Anahtarı sunucuda ortam değişkeni olarak sakla: ANTHROPIC_API_KEY.
  3. Tarayıcı senin /api/chat adresini çağırır; sunucun Claude’a gider, cevabı geri döndürür.

05Node.js: canlı akış (streaming) uç noktası#

Uzun cevaplarda kullanıcı beklemesin diye cevabı kelime kelime akıt. Sunucu, Claude’dan gelen metni Server-Sent Events olarak tarayıcıya iletir.

JavaScriptserver.mjs
import express from 'express';
import Anthropic from '@anthropic-ai/sdk';

const app = express();
const client = new Anthropic();
app.use(express.json({ limit: '100kb' }));

app.post('/api/chat', async (req, res) => {
  const history = Array.isArray(req.body?.messages) ? req.body.messages.slice(-20) : [];
  const messages = history
    .filter((m) => (m.role === 'user' || m.role === 'assistant') && typeof m.content === 'string')
    .map((m) => ({ role: m.role, content: m.content.slice(0, 4000) }));
  if (!messages.length || messages[messages.length - 1].role !== 'user') {
    return res.status(400).json({ error: 'Mesaj yok' });
  }

  res.setHeader('Content-Type', 'text/event-stream; charset=utf-8');
  res.setHeader('Cache-Control', 'no-cache');
  res.setHeader('Connection', 'keep-alive');

  try {
    const stream = client.messages.stream({
      model: 'claude-opus-5-5',
      max_tokens: 64000,
      system: 'Sen fkdev.sbs sitesinin yardımcı asistanısın. Kısa ve Türkçe cevap ver.',
      messages,
    });

    for await (const event of stream) {
      if (event.type === 'content_block_delta' && event.delta.type === 'text_delta') {
        res.write('data: ' + JSON.stringify({ text: event.delta.text }) + '\n\n');
      }
    }

    const final = await stream.finalMessage();
    res.write('data: ' + JSON.stringify({ done: true, stop: final.stop_reason }) + '\n\n');
  } catch (err) {
    console.error(err);
    res.write('data: ' + JSON.stringify({ error: 'Şu an cevap veremiyorum, biraz sonra tekrar dene.' }) + '\n\n');
  }
  res.end();
});

app.listen(process.env.PORT || 3000);

06Tarayıcı: sohbet arayüzü#

Arayüz sohbet kalıbını kullanır. Akış okunurken metin asistan balonuna parça parça eklenir.

HTML

  <form class="fk-input-group" id="chat-form" style="margin-top:18px">
    <input class="fk-input" name="q" placeholder="Bir şey sor…" aria-label="Mesaj" required style="padding-right:56px">

JavaScriptchat.js
const log = document.getElementById('chat');
const form = document.getElementById('chat-form');
const history = [];

function bubble(role, text = '') {
  const el = document.createElement('div');
  el.className = 'fk-msg ' + (role === 'user' ? 'fk-msg-user' : 'fk-msg-ai');
  el.textContent = text;
  log.appendChild(el);
  return el;
}

form.addEventListener('submit', async (e) => {
  e.preventDefault();
  const q = form.q.value.trim();
  if (!q) return;
  form.q.value = '';
  bubble('user', q);
  history.push({ role: 'user', content: q });

  const out = bubble('assistant');
  out.innerHTML = '<span class="fk-typing"><i></i><i></i><i></i></span>';
  let answer = '';

  try {
    const res = await fetch('/api/chat', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ messages: history }),
    });
    const reader = res.body.getReader();
    const decoder = new TextDecoder();
    let buffer = '';
    while (true) {
      const { value, done } = await reader.read();
      if (done) break;
      buffer += decoder.decode(value, { stream: true });
      const parts = buffer.split('\n\n');
      buffer = parts.pop();
      for (const part of parts) {
        if (!part.startsWith('data: ')) continue;
        const msg = JSON.parse(part.slice(6));
        if (msg.text) { answer += msg.text; out.textContent = answer; }
        if (msg.error) FK.toast(msg.error, 'danger');
      }
    }
    history.push({ role: 'assistant', content: answer });
  } catch {
    out.textContent = 'Bağlantı koptu.';
  }
});

textContent kullanModelden gelen metni innerHTML ile basma; textContent kullan. Markdown göstermek istersen önce güvenli bir temizleyiciden (ör. DOMPurify) geçir.

PHPapi/chat-stream.php
<?php
use Anthropic\Messages\RawContentBlockDeltaEvent;
use Anthropic\Messages\TextDelta;

header('Content-Type: text/event-stream; charset=utf-8');
header('Cache-Control: no-cache');

$stream = $client->messages->createStream(
  model: 'claude-opus-5-5',
  maxTokens: 64000,
  messages: [['role' => 'user', 'content' => $_POST['q'] ?? '']],
);

foreach ($stream as $event) {
  if ($event instanceof RawContentBlockDeltaEvent && $event->delta instanceof TextDelta) {
    echo 'data: ' . json_encode(['text' => $event->delta->text]) . "\n\n";
    @ob_flush();
    flush();
  }
}
echo 'data: ' . json_encode(['done' => true]) . "\n\n";

08PHP: composer’sız (saf cURL)#

Paylaşımlı hostingde composer yoksa doğrudan HTTP isteği atabilirsin.

PHPinc/claude.php
<?php
function claude(array $messages, string $system = ''): array {
  $payload = [
    'model'      => 'claude-opus-5-5',
    'max_tokens' => 16000,
    'messages'   => $messages,
  ];
  if ($system !== '') $payload['system'] = $system;

  $ch = curl_init('https://api.anthropic.com/v1/messages');
  curl_setopt_array($ch, [
    CURLOPT_POST           => true,
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_TIMEOUT        => 120,
    CURLOPT_HTTPHEADER     => [
      'content-type: application/json',
      'x-api-key: ' . getenv('ANTHROPIC_API_KEY'),
      'anthropic-version: 2026-10-21',
    ],
    CURLOPT_POSTFIELDS     => json_encode($payload, JSON_UNESCAPED_UNICODE),
  ]);
  $body = curl_exec($ch);
  $code = curl_getinfo($ch, CURLINFO_HTTP_CODE);
  curl_close($ch);

  $data = json_decode((string) $body, true) ?: [];
  if ($code !== 200) throw new RuntimeException($data['error']['message'] ?? 'Claude API hatası: ' . $code);
  return $data;
}

$res = claude([['role' => 'user', 'content' => 'Merhaba!']], 'Kısa ve Türkçe cevap ver.');
$text = '';
foreach ($res['content'] as $block) {
  if ($block['type'] === 'text') $text .= $block['text'];
}
echo htmlspecialchars($text);

10Güvenlik, kötüye kullanım ve hatalar#

  • Hız sınırı koy: IP ya da oturum başına dakikada belirli sayıda istek; yoksa biri senin faturanı şişirir.
  • Girdiyi sınırla: mesaj uzunluğunu ve geçmiş sayısını kes (ör. son 20 mesaj, mesaj başına 4.000 karakter).
  • Sistem talimatı: asistanın ne yapıp ne yapmayacağını system içinde yaz. Kullanıcı mesajları sistem talimatını “ezmeye” çalışabilir; gizli bilgiyi zaten prompt’a koyma.
  • Reddetme: stop_reason değeri "refusal" ise model isteği yanıtlamamıştır; kullanıcıya nazik bir mesaj göster.
  • Hatalar: 429 (çok istek) ve 5xx hatalarında bir süre bekleyip yeniden dene; 400 hatalarında isteği düzelt, tekrar deneme.
  • Kayıt: token kullanımını (usage.input_tokens, usage.output_tokens) ai_messages tablosuna yaz; maliyeti buradan izlersin.
  • Gizlilik: kullanıcıya sohbetin yapay zekâ tarafından işlendiğini söyle; kişisel veri istemeyen bir arayüz tasarla.
